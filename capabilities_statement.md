## Core Competency

Golden-Agent is a local-first agent runtime that keeps autonomous systems
operating without cloud connectivity. It monitors its own host through live
hardware telemetry, throttles its execution loops to stay responsive under
load, and recovers from faults without operator intervention. Performance-
critical paths run in a native C++17 accelerator, and state and model weights
are encrypted at rest with key rotation support.
