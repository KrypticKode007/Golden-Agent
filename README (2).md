# Golden-Agent (`v5.0.0`)

**Kryptic Shield Core Engine & Real-Time Cognitive AI Assistant Monolith**

A zero-dependency, self-healing Python monolith combining fault-isolated telemetry, cryptographic HMAC verification, human brain neuro-architecture modeling, an 11-step daily routine & rapid learning engine, biomedical longevity science, and *The Game of Life and How to Play It* codex.

## Quick Start

```bash
# Run full self-healing and cryptographic verification suite
python3 golden_agent-v8.py --verify

# Start real-time interactive AI assistant chat
python3 golden_agent-v8.py --chat

# Ask a single question
python3 golden_agent-v8.py --ask "Walk me through my daily routine and give me an affirmation"

# Inspect individual modules
python3 golden_agent-v8.py --routine
python3 golden_agent-v8.py --brain all
python3 golden_agent-v8.py --simulate-pathway "Waking up and preparing for deep work"
python3 golden_agent-v8.py --game-of-life
python3 golden_agent-v8.py --affirm "clarity"
python3 golden_agent-v8.py --export-manifest
```

## Optional Live LLM Augmentation

`golden_agent-v8.py` runs out of the box with **zero external dependencies**. To augment its local deterministic cognitive engine with live generative responses, set `OPENAI_API_KEY`:

```bash
export OPENAI_API_KEY="your-api-key"
python3 golden_agent-v8.py --chat
```
