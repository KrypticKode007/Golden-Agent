# Golden-Agent
An Asynchronous Active Inference & Phenomenological Cybernetic Core.

## System Components
- `main_sentience_core.py`: Evaluates active inference metrics and manages the asynchronous local socket loop broadcast on port `8000`.
- `vr_pov_monitor.py`: Real-time tracking subscriber client that logs the agent's phenomenological experiences to `cognitive_pov_history.txt`.
- `agency_sentience.db`: Local transactional database for belief vectors and episodic memory caching.

## Operational Metrics
- **Variational Free Energy**: System surprise vector.
- **Individuation Drive**: Autonomous drift index away from present constraints.
- **Informational Closure**: Degree of autonomous self-dependence.
